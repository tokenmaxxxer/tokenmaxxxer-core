# Scout brief — issue-114 step 2

**Pass shape.** 2 stages of the 5 allowed, inside the 3-minute budget: stage 1 a
genuinely concurrent 3-angle sweep (three read-only `Explore` subagents dispatched in
one message — habitat inventory / class ledger / house-format exemplars), stage 2 one
judge point, which found the angles overlapping on the same conclusion and stopped
deepening. Mode: **parallel**, not batched-sequential. Corpus: this repository's own
prior artifacts — no web angle was run, because the deliverable's kind (an
execution-observation record under role-handoff contract v3) has no external
best-in-class corpus; its exemplars are the six prior instances in this repo.

**Category must-bes** (what every strong prior instance of this deliverable does):
independence statement first, with an explicit "no verdict language appears above this
point" boundary line; three sibling verdict sections in fixed order (outcome →
trajectory → step), each led by a bolded one-line headline; every verdict-bearing
sentence carrying a `<sha>:<path>:<line>` citation adjacent to the claim; findings in
the four-part blameless shape (Impact / Timeline / Root cause / Action item) with the
action item explicitly the human's to file; an explicit `## What is not deficient`;
and a stated method-limits section naming what was out of reach.

**Performance axes** the strongest instances visibly compete on: (1) evidence tiering —
marking each claim artifact-derived vs. analytic vs. out-of-reach rather than flattening
them; (2) trajectory rendered as a timestamped table with a source column, so ordering is
proved rather than asserted; (3) checking whether prior observation findings' *classes*
recur in the delivery under observation, instead of judging it in isolation.

**Adopt**: the timestamped trajectory table; per-claim evidence tiers; the survey-unknowns
(U1…Un) carried forward and adjudicated one by one in the record.
**Skip**: the `loop_state: phase-1` older dialect (superseded by
`scouted`/`surveyed`/`phase-1`/`landed`); the `sha: <set at commit>` placeholder in
proposal frontmatter — a prior record charged exactly that as a finding.

**Gap line.** Met already by the current state: this session has read PR #115, both its
commits, and the observed record directly, and the three verdict levels are named before
any verdict language. Missing, and therefore what this pass aims at: (a) the population
question — whether the wrapper parser-differential class is exhausted — which no prior
instance in this repo has had to answer as a whole-population claim, and (b) a per-site
direction call (fail-closed vs fail-open) for each candidate habitat, which the priors
only ever did for the single site they observed.

**Segment fit.** Same segment as the six prior execution-observation records; the one
scale difference is the population question, which raises the evidence bar rather than
the format.
